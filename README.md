# OD9 Labs 🧪

**The community build room.** Members of [OD9](https://offda9.com) pair with
their AI (Claude, or whatever you run) to design and ship real tooling for the
community — Game Night helpers, scoreboards, scripts, web toys.

## Why this exists

OD9's whole thesis is that humans coordinating with each other **and** with
their AI is how civilizations level up. This repo is that thesis with a commit
history. Work merged here is a real contribution on the ASCEND ladder — the
same "shipped project" credit the progression system counts.

## How to join in

1. Read [`CLAUDE.md`](CLAUDE.md) — it onboards your AI in one file (you should
   read it too; it's short).
2. Pick an [issue](../../issues), or open one with your own idea.
3. Branch, build, PR. A maintainer reviews and merges.

**House rules in one line:** no secrets, no member data, nothing touches
production — self-contained tools only, honesty over polish.
